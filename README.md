# 🛒 Pinia do Zero – Carrinho de Compras

Este repositório faz parte da playlist **"Pinia na Prática — Mini Carrinho do Zero"** no YouTube, onde construímos, passo a passo, um **Carrinho de Compras** usando **Pinia**, do início até a aplicação completa.

🔗 [Assista à playlist completa no YouTube](https://www.youtube.com/playlist?list=PLcoYAcR89n-rLKkJyiuDe_nnAawMmDooL)

## 🎯 Objetivo do Projeto

Aprenda **Pinia** construindo um projeto desde o início, com conceitos explicados no momento em que fazem sentido. **Sem backend ou API** — foco total em **state management, stores, actions, getters e fluxo de dados reativo**.

Ideal para quem já trabalha com Vue 3 mas quer dominar o gerenciamento de estado com Pinia, ou está migrando do Vuex e quer entender a nova forma recomendada de gerenciar estado.

## 🧩 O que estamos construindo

Um **Carrinho de Compras** completo com adicionar produtos, listar itens, remover produtos, alterar quantidades, calcular valor total e resetar o carrinho. Os dados ficam **em memória** (não são persistidos) para manter o foco no Pinia.

## 🛠️ Tecnologias

- **Vue 3** (Composition API)
- **Pinia**
- **Vite**
- **HTML + CSS**

## 🧱 Como acompanhar

👉 **Cada branch representa uma aula da playlist no YouTube.**

- **`main`**: Contém a documentação do projeto (README)
- **`template-html`**: Contém o layout HTML de referência (apenas HTML + CSS, sem Javascript e sem Vue)
- **`aula-01`**, **`aula-02`**, **`aula-03`**, etc.: Cada branch contém o código completo do projeto ao final daquela aula

**Conceitos abordados:** Stores, state, actions, getters, composables, persistência de dados, reatividade e fluxo de dados centralizado.
